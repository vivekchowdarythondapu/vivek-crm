# Walkthrough video — 3 min script (draft)

Structure per the brief: the five answers for one account, one number traced
to its source, it picking up something new, the code briefly.

## 0:00–0:20 — What this is
"My manager gets one screen for two accounts. Every number on it points at
the record it came from. Here is account A."

## 0:20–1:40 — The five answers (one account)
- Book worth: deals listed at backed values; the unbacked estimate sits apart.
- Power: who decides / pays / uses / blocks, and where each stands with me.
- First three moves: ranked, each with owner, date, and the deal it moves.
- About to go wrong: the December 5 event deadline, Karen's unanswered
  written request, Rhys leaving in January with no successor.
- Don't know: the gaps, why each matters, who could fill it.

## 1:40–2:10 — Trace one number live
"$60,000 priority support — this is not my claim. It comes from record
[file id] in the paperwork, and you can see the id printed under the number."
Open the source record on screen.

## 2:10–2:35 — It picks up something new
Show get_signals: the Aldermoor three docks that went silent, arriving without
a reload. Show a note the dashboard wrote back with write_note.

## 2:35–3:00 — Code briefly
"The browser never touches the token — one server route calls the MCP, one
call per minute enforced in lib/mcp.js, everything cached after the first
fetch. README has the run steps."
